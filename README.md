Overview
This repository contains the MATLAB and R code supporting the above paper. Two separate Dynamic Energy Budget (DEB) models were developed for the Northern Star Coral Astrangia poculata under two naturally occurring symbiotic states — symbiotic (harboring Symbiodinium algae) and aposymbiotic (relatively free of symbionts) — within the Add-my-Pet (AmP) framework. Both models use the standard (std) DEB model structure and are fitted to temperature–respiration data and life history data using MATLAB's DEBtool.

MATLAB File Descriptions
Each model follows the standard four-file AmP structure. Both models use the std model type.
mydata_Astrangia_poculata_[sym/apo].m — Data files
Defines all empirical data, metadata, and auxiliary data used to constrain parameter estimation.


pars_init_Astrangia_poculata_[sym/apo].m — Initial parameter files
Defines starting values and freedom flags for all DEB parameters. Free parameters (estimated) are flagged with free.X = 1; fixed parameters with free.X = 0.

predict_Astrangia_poculata_[sym/apo].m — Prediction functions
Computes model predictions from the current parameter set for comparison against data. Called internally by estim_pars during optimization.
Key computations:
Temperature correction using a two-boundary Arrhenius function (tempcorr with [T_A, T_H, T_AH]), capturing both the Arrhenius temperature and the upper thermal tolerance boundary
Life stage timing via get_tp — computes dimensionless times and lengths at birth and puberty
Egg volume and diameter computed from initial scaled reserve (initial_scaled_reserve) assuming a spherical egg geometry: Lw_0 = ((V_egg * 6 / π)^(1/3))
O₂ consumption prediction via scaled_power → mineral flux matrix → conversion to µmol O₂/g dry weight/d, with per-temperature correction applied using the Arrhenius function evaluated at each observed temperature
Functional response note: A custom combined food + light functional response (f_coral) is defined but not used in the final predictions (standard f = 1 is applied instead). This infrastructure is retained for future development.

run_Astrangia_poculata_[sym/apo].m — Run scripts
Launches parameter estimation using the Nelder-Mead (nm) simplex algorithm via DEBtool's estim_pars.
After estimation, the scripts load the saved .mat file and print the compound parameters p_Am (max surface-specific assimilation rate, J/d·cm²) and E_m (maximum reserve density, J/cm³).

extract_predictions_[symbiotic/apo].m — Prediction export scripts
Post-estimation utility scripts that reload the saved results, re-run the prediction function, and export the temperature–respiration predictions (observed and predicted) to CSV for visualization in R.
Output files:
TJO_predictions_SYM.csv — columns: temperature, resp_obs, resp_pred
TJO_predictions_APO.csv — columns: temperature, resp_obs, resp_pred
Note: Predicted respiration values may include small imaginary components due to numerical precision in MATLAB's matrix operations. The R visualization script removes these with Re() before plotting.

R File Description
AmP_visualizations.Rmd — Visualization script
Reads the exported CSV predictions and produces publication-quality figures comparing symbiotic and aposymbiotic respiration responses.
Key figures:
Separate temperature–respiration plots for each symbiotic state (observed points + LOESS-smoothed predicted line)
Combined figure overlaying both states with jittered observed points and LOESS-smoothed predictions; color-coded (aposymbiotic = #636363 grey; symbiotic = #964B00 brown)
Predicted-only overlay (no data points) for a cleaner comparison of the DEB model curves
Output: high_res_TJO_plot.png (300 dpi)

Recommended Execution Order
MATLAB — Parameter estimation:


Run run_Astrangia_poculata_sym.m with method = 'nm' to estimate parameters for the symbiotic model
Run run_Astrangia_poculata_apo.m with method = 'nm' to estimate parameters for the aposymbiotic model
Results are saved automatically to results_Astrangia_poculata_[sym/apo].mat
MATLAB — Export predictions:


Run extract_predictions_symbiotic.m → produces TJO_predictions_SYM.csv
Run extract_predictions_apo.m → produces TJO_predictions_APO.csv
R — Visualization:


Open AmP_visualizations.Rmd and update the CSV file paths to match your local directory
Knit or run chunks to produce comparison figures
